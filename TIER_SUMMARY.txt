║                         QUICK COMMANDS                                    ║
╚══════════════════════════════════════════════════════════════════════════╝

Start a profile:
  ./scripts/start-services.sh minimal
  ./scripts/start-services.sh standard
  ./scripts/start-services.sh production
  ./scripts/start-services.sh full

Toggle tiers:
  ./scripts/toggle-tier.sh monitoring on
  ./scripts/toggle-tier.sh advanced-monitoring off
  ./scripts/toggle-tier.sh security on
  ./scripts/toggle-tier.sh observability off
  ./scripts/toggle-tier.sh performance on

Check status:
  ./scripts/service-status.sh

╔══════════════════════════════════════════════════════════════════════════╗
║                      STARTUP STAGE RECOMMENDATIONS                        ║
╚══════════════════════════════════════════════════════════════════════════╝

🌱 Bootstrapping (< $5k MRR)
   → minimal profile (4 CPU, 3GB RAM)
   → Focus on product, not infrastructure

🚀 Early Traction ($5k - $20k MRR)
   → standard profile (6.5 CPU, 4.6GB RAM)
   → Add basic monitoring to catch issues

📈 Growth ($20k - $100k MRR)
   → production profile (9 CPU, 6GB RAM)
   → Need security, performance, observability

🏢 Scale ($100k+ MRR)
   → full profile (12.5 CPU, 7GB RAM)
   → Compliance, audit trails, max reliability
